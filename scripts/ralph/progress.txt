- AppLayout at `src/components/layout/AppLayout.tsx` — wraps all `(dashboard)` routes

  - `users` table: id, email, full_name, company_name, industry, role_title, onboarding_completed, ci_experience_level, miestro_linked, role, created_at, updated_at
  - `user_progress` table: id, user_id (FK), stage (enum), status (enum), completed_at, created_at — UNIQUE(user_id, stage)

- Files changed: src/db/migrations/001_core_tables.sql, src/db/types.ts, src/db/AGENTS.md, AGENTS.md
- **Learnings for future iterations:**
  - Use CHECK constraints for enum-like columns in PostgreSQL (not actual ENUM types) — easier to extend later
  - UNIQUE(user_id, stage) prevents duplicate progress rows per stage

  - CASCADE delete on FK means deleting a user cleans up their progress and milestones

## 2026-02-23 - US-004
Session: Tracker and chat database schema
- Created SQL migration at `src/db/migrations/002_tracker_tables.sql` with:
  - `improvement_opportunities` table: CRUD for workplace waste tracking, priority/status filters, updated_at trigger
  - `war_battle_sessions` table: 14-week battle tracking with battle_number (1-3), week_number (1-14), powerpoint_link, status
  - `winning_solutions` table: before/after metrics with metric_type enum, NUMERIC values for calculations
  - `success_nuggets` table: achievement statements with source (manual/ai_generated), updated_at trigger
  - `conversations` table: CI Professor chat threads
  - `messages` table: chat messages with role (user/assistant), FK to conversations with CASCADE
  - `book_embeddings` table: pgvector(1536) for RAG, HNSW index for cosine similarity
  - RLS policies: all tables — users CRUD own rows, admin can read all
  - Messages RLS uses join-based policy checking parent conversation's user_id
  - Book embeddings: read for all authenticated users, insert restricted to admin
  - Indexes on all foreign keys, status/priority columns, and HNSW on embeddings
- Updated `src/db/types.ts` with new interfaces and insert types:
  - ImprovementOpportunity, WarBattleSession, WinningSolution, SuccessNugget
  - Conversation, Message, BookEmbedding
  - All corresponding Insert types and union types for enums
- Updated `src/db/AGENTS.md` with tracker, chat, and embeddings sections
- Updated root `AGENTS.md` with new import patterns
- Files changed: src/db/migrations/002_tracker_tables.sql, src/db/types.ts, src/db/AGENTS.md, AGENTS.md
- **Learnings for future iterations:**
  - pgvector uses `vector(1536)` type — 1536 dimensions matches OpenAI embedding models
  - HNSW index with `vector_cosine_ops` is preferred for cosine similarity search (faster than IVFFlat)
  - Messages RLS requires join to conversations table — use EXISTS subquery pattern
  - Book embeddings have no user_id — shared resource, authenticated read, admin-only write
  - `NUMERIC` type used for before/after values (not FLOAT) to avoid floating point precision issues
  - Reuse `update_updated_at_column()` trigger function from migration 001 — no need to recreate
