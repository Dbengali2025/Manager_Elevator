## Codebase Patterns
- AppLayout at `src/components/layout/AppLayout.tsx` — wraps all `(dashboard)` routes
- Route group `app/(dashboard)/layout.tsx` applies AppLayout to all authenticated pages
- Sidebar nav items defined in `navigation` array in AppLayout — add new routes there
- Mobile sidebar uses Headless UI Dialog + Transition (breakpoint: md/768px)
- Insforge client at `src/lib/insforge.ts` — use `insforgeClient.from("table")` for REST, `insforgeAuth` for auth
- All Insforge methods return `{ data, error }` — always check error first
- PostgREST query syntax for filtering: `"?column=eq.value&other=gt.5"`
- Dashboard page is a Server Component — `getDashboardData()` fetches user name + progress records
- Dashboard components in `src/components/dashboard/` — import as `@/components/dashboard/ComponentName`
- Database types at `src/db/types.ts` — import `User`, `UserProgress`, `Milestone`, `STAGE_ORDER`
- SQL migrations in `src/db/migrations/` — named `NNN_description.sql`, use `IF NOT EXISTS`
